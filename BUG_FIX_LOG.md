# Bug Fix Log (Stage 1)

Every bug below was reproduced before it was fixed, either by a failing
Playwright test (`tests/grading.spec.js`, test names start with `#N`) or by
the manual steps listed. Fixtures are in `fixtures/` and are generated by
`node fixtures/generate.js`.

| # | Bug / Issue Identified | How You Reproduced It | Root Cause | Fix Implemented | How You Tested the Fix |
|---|---|---|---|---|---|
| 1 | Min and Max statistics are swapped. | Uploaded `valid_basic.xlsx`, selected CS F211 (marks 0–100). The "Min" tile showed 100 and "Max" showed 0. | The markup puts `id="max"` inside the "Min" tile and `id="min"` inside the "Max" tile. `computeStats` writes the smallest mark into `#min`, which is the element labelled "Max". | Swapped the two ids so each label wraps the matching element. | Test `#1`: expects Min = 0 and Max = 100 for CS F211. It failed before the fix and passes after. |
| 2 | Course dropdown lists each course once per student, and a second upload keeps the old courses, grade ranges, stats, histogram, summary and welcome text. | Uploaded `valid_basic.xlsx` (2 courses, 40 rows): the dropdown had 41 options. Selected a course, then uploaded `valid_second.xlsx`: the old courses and the old analytics were still on screen. | The upload handler adds `new Option` for every row's `Course` value without removing duplicates, and never clears the select or any UI built from the previous file. | Added `resetGradingView()`, which clears the grade cards, range error, summary, welcome text, stats (shown as "—") and histogram, and disables Download. Each upload clears `data`, trims the select back to its placeholder, calls the reset, and adds one option per distinct course (`new Set`). | Test `#2`: checks the options are exactly the distinct courses after each upload, and that the select, grade UI, summary, welcome, stats, canvas and Download button are all reset after re-upload. It failed before the fix and passes after. |
| 3 | The file picker only accepts `.xls`, but the brief specifies `.xlsx`. | Inspected the input: test `#3` read `accept=".xls"`. With that value, browsers filter the file dialog to `.xls`, so an `.xlsx` file can only be picked by switching the dialog to "All files". | The `accept` attribute lists only the legacy extension. | Changed it to `accept=".xlsx,.xls"`. SheetJS already reads both formats. | Test `#3` asserts both extensions are accepted (failed before, passes after). Manual check: click "Choose File" and confirm `.xlsx` files are selectable without changing the dialog filter. |
